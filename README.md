# BuckTracks (dev mirror)

This repo holds the full **Next.js** UI for the northern Nova Scotia deer hunting platform.

**Canonical product home:** **[https://github.com/aross197/bucktracks](https://github.com/aross197/bucktracks)**

- Live browser social: https://aross197.github.io/bucktracks/
- Platform core (`platform/`): schema, seasons, geo, package — in **bucktracks**
- Full app routes (landing, feed, cams, safety, dashboard): **this repo**

## Features

- Crew Feed (post kills, react, comment)
- Mass Dump Trail Cam Reader
- I Am Lost (GPS + back bearing + email)
- 2026–2027 NS seasons
- Premium cinematic UI

```bash
git clone https://github.com/aross197/NS-Deer-Paradise.git
cd NS-Deer-Paradise
npm install && npm run dev
```

Or work from `bucktracks/platform` + merge this `app/` tree and rebrand to **BuckTracks**.

Hunt safe. Hunt ethical.
